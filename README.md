# Brand Insight 品牌消费者洞察平台

这是一个面向品牌经理、消费者洞察与电商运营团队的 B2B 分析网站。公开首页说明平台价值和 Search → Segment → Analyze → Act 工作流；“赫莲娜小露珠”作为已接入的真实案例，展示从官方主张、消费者反馈、对照判断、采集原文到行动建议的完整链路。

## 本版信息架构

- `/`：公开平台首页，顶部导航、平台能力、四步工作流、案例入口与统一 CTA。
- `/workspace`：小露珠项目总览，30 秒概览、样本范围、品牌方一页纸、关键发现和对照主题。
- `/claims`：品牌主张。
- `/consumer`：消费者洞察，按产品体验、购买动机、改进机会和竞品分析组织。
- `/compare`：品牌表达与消费者反馈对照。
- `/actions`：行动建议，固定呈现发现、原文、建议动作、负责团队和拟验证指标。
- `/evidence`：用户反馈，支持关键词、记录号、平台、内容类型、主题、情感筛选及当前结果 CSV 导出。
- `/data`：CSV/XLSX 文件导入、预览、映射、校验、确认与真实查询复核。

公开首页采用顶部导航与长页营销结构；进入案例后切换为固定左侧导航和高密度分析页面。视觉使用暖白、玫瑰豆沙与深棕黑，图表、样本口径和数据缺失状态均在界面内明确标示。

## 已交付能力

- 6,610 条只读统一明细种子，稳定案例前缀 `xlz-case-v1`；试验数据集前缀 `xlz-sandbox-v1`。
- 品牌主张、消费者洞察、对照判断、采集原文和行动建议之间的可复核链接。
- 原文抽屉保留采集内容；天猫打开商品页，抖音与小红书打开对应父内容。
- 中文关键词与记录号检索，主题、情感、平台和内容类型筛选，当前筛选结果导出。
- CSV/XLSX 导入：20 MB 上限、Sheet 选择、前 20 行预览、字段映射、必填校验、重复跳过、ID 冲突报告、原子写入和写入后真实查询。
- 原文件按批次保存，解析结果与原文件分离；导入只允许写入试验数据集。
- 本地静态资源、图表代码、API 与 SQLite 数据，无 CDN、远程字体或远程脚本依赖。

## 安装、构建与启动

环境要求：Python 3.9+、Node.js 18+、pnpm 9+。首次安装依赖需要联网；完成安装与构建后，本地启动和浏览不依赖外网。首次生成案例数据库前，还需将已授权的 `小露珠_数据整理总表.xlsx` 与 `网页文案证据.csv` 放入本地 `data/source/`。

```bash
scripts/bootstrap.sh
scripts/start.sh
```

访问 <http://127.0.0.1:8000>。也可分别执行：

```bash
scripts/seed.sh
scripts/build.sh
scripts/start.sh
```

等价命令：`make install`、`make seed`、`make build`、`make start`、`make test`。端口冲突时使用 `PORT=8010 scripts/start.sh`。

## 备份与恢复

```bash
scripts/backup.sh
scripts/restore.sh data/backups/xiaoluzhu-YYYYMMDD-HHMMSS.sqlite3
```

备份使用 SQLite 在线备份接口生成一致性快照。恢复脚本会验证快照并先备份当前数据库；恢复前应停止服务。`data/source`、`data/uploads` 与 `data/demo` 不会被数据库恢复覆盖。

## 答辩演示步骤

1. 打开 `/`，说明平台价值和“检索 → 分类 → 分析 → 行动”流程，点击“进入小露珠案例”。
2. 在 `/workspace` 查看 30 秒概览、品牌方一页纸、关键发现与样本口径。
3. 打开“消费者洞察”或“品牌表达对照”，从判断进入真实原文，再返回查看关联建议。
4. 在“用户反馈”输入“干皮单用”，确认返回 2 条记录；打开 `20261029_T00238` 查看原文和商品页来源。
5. 在“行动建议”复核发现、原文、负责团队和拟验证指标。
6. 在“数据管理”选择 CSV/XLSX，完成预览、映射、校验和试验数据写入；写入后用真实查询检索新增记录。
